# プロジェクト技術決定事項

作成日：2026年5月31日

---

## 概要

小規模Webアプリケーション（想定ユーザー規模：〜1,000人）の技術スタックおよびインフラ構成に関する決定事項をまとめる。

---

## アーキテクチャ

3層構成（フロントエンド / バックエンド / データベース）をベースとするシンプルな構成を採用する。

---

## 技術スタック

### フロントエンド

| 項目 | 採用技術 |
|------|----------|
| フレームワーク | React |
| ビルドツール | Vite |
| UIコンポーネント | shadcn/ui |
| スタイリング | Tailwind CSS |
| 状態管理 | TanStack Query |

**選定理由**
- React + Vite の組み合わせにより、高速な開発環境と優れたDX（開発体験）を確保する
- shadcn/ui + Tailwind CSS により、デザイン品質を担保しながら実装スピードを高める
- TanStack Query によりサーバーデータの取得・キャッシュを効率的に管理する

### バックエンド

| 項目 | 採用技術 |
|------|----------|
| フレームワーク | Hono（Node.js） |
| 通信方式 | REST API（HTTPS） |

**選定理由**
- 軽量かつ高速なAPIフレームワークであり、小規模サービスに適している
- TypeScript ネイティブ対応のため、フロントエンドとの型共有が容易

### データベース・認証

| 項目 | 採用技術 |
|------|----------|
| データベース | Supabase（PostgreSQL） |
| 認証 | Supabase Auth |
| ストレージ | Supabase Storage（必要に応じて） |

**選定理由**
- DB・認証・ストレージを一体で管理でき、小規模開発の運用負荷を下げられる
- メール認証・OAuthログイン（Google / GitHub）がすぐに利用可能

---

## インフラ

### ホスティング：Vercel

| 項目 | 内容 |
|------|------|
| 対象 | フロントエンド（React + Vite） |
| 料金プラン | 無料（Hobby プラン） |
| デプロイ方式 | Git連携による自動デプロイ |
| 無料枠 | 帯域 100GB/月、商用利用可 |

**選定理由**
- Gitへのpushだけで自動デプロイが完結し、CI/CDの初期構築が不要
- グローバルCDNにより、国内外問わず高速なアクセスが可能
- React / Vite プロジェクトとの親和性が高い

### その他インフラ（参考）

| サービス | 用途 | 無料枠 |
|----------|------|--------|
| Render | バックエンドホスティング | 750時間/月（スリープあり） |
| Supabase | DB・認証・ストレージ | DB 500MB、ストレージ 1GB |

> **注意：** Render の無料プランは15分無操作でスリープ。初回アクセス時に数秒の遅延が生じる。
> Supabase は7日間非アクティブでプロジェクトが一時停止する。
