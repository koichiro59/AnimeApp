# SEO改善ループ (aniref.net)

## 目的
Google検索からの**流入を無料で増やす**。有料API(DeepL/Claude)は使わない。
中心課題: 20,910キャラ中インデックス約2,747のみ。薄コンテンツで大半が「検出-未登録」。

## 制約（必読）
- **有料API禁止**。AniList(無料GraphQL)・既存フィールドからの生成はOK。
- **Supabase直接書き込み禁止**。データ更新はSQLファイル生成→ユーザー手動適用。
- コード変更は `seo-loop` ブランチにコミット→**mainへff-mergeまでユーザー承認済み**（都度確認不要）。
- テンプレ生成文の表示はユーザー承認済み。
- バックグラウンド実行。**各イテレーションの冒頭と結果を1〜2行でチャットに表示**し進捗を可視化する。

## 1イテレーションの型
1. **表示**: 「▶ seo-loop: 今から〈施策名〉に着手」とチャットに1行出す。
2. **選択**: 下のバックログから未完の最優先1件（または `git log --oneline` で進捗確認）。
3. **実装**: 1施策だけ。影響の広い調査は Explore / fork agent に委譲してcontext節約。
4. **検証**: `npx tsc --noEmit` でビルド確認。データ系は小サンプルで出力確認。
5. **コミット→マージ**: `seo-loop` に1施策=1コミット→`git checkout main && git merge seo-loop --ff-only`→`seo-loop`へ戻る。
6. **表示**: 「✅ 完了: 〈コミットhash 要約〉／次は〈次の施策〉」とチャットに1行出す。
7. **記録**: 区切りで MEMORY.md を更新。
