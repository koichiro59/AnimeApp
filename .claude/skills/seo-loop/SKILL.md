# SEO改善ループ (aniref.net)

## 目的
Google検索からの**流入を無料で増やす**。有料API(DeepL/Claude)は使わない。
中心課題: 20,910キャラ中インデックス約2,747のみ。薄コンテンツで大半が「検出-未登録」。

## 制約（必読）
- **有料API禁止**。AniList(無料GraphQL)・既存フィールドからの生成はOK。
- **Supabase直接書き込み禁止**。データ更新はSQLファイル生成→ユーザー手動適用。
- コード変更は `seo-loop` ブランチに自動コミット（main直コミット禁止）。
- テンプレ生成文の表示はユーザー承認済み。

## 1イテレーションの型
1. **選択**: 下のバックログから未完の最優先1件を選ぶ（または `git log --oneline` で進捗確認）。
2. **実装**: 1施策だけ。影響の広い調査は Explore / fork agent に委譲してcontext節約。
3. **検証**: `npx tsc --noEmit` でビルド確認。データ系は小サンプルで出力確認。
4. **コミット**: `seo-loop` ブランチに1施策=1コミット。日本語メッセージ + Co-Authored-By。
5. **記録**: 区切りで MEMORY.md に1行追記（CLAUDE.mdのルール準拠）。
