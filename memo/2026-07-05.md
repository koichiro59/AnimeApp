# 改善提案メモ（2026-07-05）

---

## 新規機能

### 1. ジャンル・放送期フィルター
- アニメ一覧にジャンルタグや放送クール（春/夏/秋/冬）で絞り込めるフィルターを追加
- 現状は検索バーのタイトル検索のみで、ジャンルで探せない
- ジャンルは既に `anime_genres` テーブルに存在するので実装コストは低い

### 2. グローバル検索
- ヘッダーからアニメとキャラクターをまとめて横断検索できる機能
- 現状アニメ検索・キャラ検索がページ別に分かれており、どちらにいるかわからないユーザーが迷う

### 3. お気に入り機能
- キャラ・アニメページにブックマークボタンを設置し、LocalStorage に保存
- 再訪問時に「お気に入り」ページから一覧できる
- ログイン不要で実装可能

### 4. 関連アニメ表示
- アニメ詳細ページの下部に、同ジャンルの別作品を「関連作品」として表示
- サイト内回遊を促しページビュー増加につながる

### 5. 放送シーズン別ページ
- 「2024年秋」などクール単位でアニメを一覧できるページを追加
- `broadcast_season` カラムが既にあるので実装可能

### 6. SNS シェアボタン
- アニメ・キャラ詳細ページに X(Twitter) / LINE のシェアボタンを追加
- OGP は既に設定済みなので、シェアボタンを置くだけで機能する

### 7. キャラクタースペック比較
- 複数キャラを選んで身長・体重・年齢を並べて比較できる機能
- キャラ詳細ページに「比較に追加」ボタンを設置

### 8. ランダムピックアップ
- ホームページやキャラ一覧に「今日のおすすめキャラ」などランダム表示を追加
- サイト訪問のたびに違うキャラが見られる体験を提供し、リピート訪問を促す

### 9. 声優情報の追加
- キャラクターに声優名を紐付けて表示する
- 「この声優が演じるキャラ一覧」のページも将来的に作れる
- DB への `voice_actor` カラム追加が必要

## 既存機能の改善

### 1. 画像取得できないアニメ・キャラの修正
- 「俺だけレベルアップな件」など AniList ID が未設定・不正なレコードが存在する
- Supabase 上のデータを確認し、正しい `anilist_id` を設定する
- 対象レコードの洗い出しクエリ例：
  ```sql
  SELECT * FROM animes WHERE anilist_id IS NULL;
  SELECT * FROM characters WHERE anilist_id IS NULL;
  ```

### 2. エラーハンドリングの追加
- 現状、データ取得失敗時にページが壊れた状態になる（`throw error` のみ）
- 各ページに try-catch とエラー表示 UI を追加する
- 特にネットワーク切断時や AniList API 障害時の対応が必要

### 3. ページネーション URL 反映
- 現状ページ番号が URL に含まれないため、ブラウザの「戻る」でページ 1 に戻ってしまう
- `?page=2` のようにクエリパラメータで管理するよう修正する
- 特定ページを URL でシェアできるようになる

### 4. キャラ一覧カードにアニメ名を表示
- 現状のキャラカードにはアニメ名が表示されていないため、どの作品のキャラかわからない
- `characters` テーブルには `anime_id` があるので JOIN して表示可能
- または `animes` テーブルとの JOIN クエリを `fetchCharacters` に追加する

### 5. 画像キャッシュの永続化
- 現状の `imageCache.ts` はメモリキャッシュのみで、ページリロードのたびに AniList API を再度叩く
- `localStorage` に保存することで API 呼び出し回数を削減できる
- AniList API にはレートリミットがあるため、アクセスが増えると問題になる可能性がある

### 6. アニメ・キャラ情報の充実
- `synopsis`（あらすじ）、`author`（原作者）、`episodes`（話数）が未設定のアニメが存在する
- `description`・`age`・`gender`・`height`・`weight` が null のキャラも多い
- 詳細ページで表示項目がスカスカになっている箇所の確認と補完が必要

### 7. 一覧ページの SEO 対応
- ホームページ・アニメ一覧・キャラ一覧に `<title>` と `<meta description>` が設定されていない
- アニメ詳細・キャラ詳細には `react-helmet-async` 設定済みだが、一覧系ページが未対応

### 8. ホームページのピックアップ選出ロジック改善
- 現状は DB の先頭 12 件から画像ありの 6 件を表示するだけ
- アクセス数・更新日時・ランダムなど、より意図的な選出基準を設けることでサイトの質が上がる
